# File Header Policy

Every human-authored implementation/documentation/configuration artifact declares:

- file path or context;
- purpose;
- author: **Raushan Raj**.

Formats that support comments use a leading comment/docstring. JSON uses `x-file-purpose` and `x-author` metadata. Package metadata uses its standard `description` and `author` fields and additionally carries the `x-*` metadata generated by this repository.

Generated build output is excluded from this requirement and from release source control.
