# Dashboard

The v1.0 repository includes the dashboard boundary rather than tying the product to a specific front-end framework. The control plane exposes stable normalized data contracts; a later UI can use React, Vue, Angular, or an embedded enterprise shell without changing the quality kernel.

Initial dashboard domains:

- Execution health across automation tools and languages.
- LLM/RAG/agent evaluation trends.
- Adapter health and compatibility status.
- Evidence and audit events.
- Release gates and regression signals.
